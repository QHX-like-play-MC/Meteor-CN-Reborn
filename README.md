# Meteor 精修汉化版（dingzhenI18n 方案）

> 基于 **dingzhenI18n（Meteor-I18n-Support-plugin）** 的 Meteor Client 中文汉化项目。
> 不替换原始 JAR，通过语言文件注入实现中文显示，并对核心模块翻译进行人工精修。

---

## 项目简介

Meteor Client 官方未提供中文界面支持，其界面文本以硬编码形式写入代码，早期汉化方案通常采用“替换 JAR 内文本”的方式，代价是配置兼容性下降、每次 Meteor 更新都需要重新打包。**dingzhenI18n**（即 `Meteor-I18n-Support-plugin`）改变了这一局面：它以 Meteor 插件的形式，通过 Mixin 将硬编码文字抽离至独立的 `lang` 语言文件中，使文本可以在不改动原始 JAR 的前提下被翻译，同时一并修复了 Meteor 自定义字体渲染对中文的兼容问题。

**Meteor 精修汉化版**是在 dingzhenI18n 插件基础上维护的**语言文件精修项目**。它不修改 Meteor 本体，也不修改插件逻辑，只专注于一件事：让 `lang` 文件中的中文翻译更加准确、可读、贴近 Minecraft 社区用语习惯。


## 核心特性

### 非硬编码汉化，与 Meteor 本体解耦

汉化不再依赖替换原始 JAR。dingzhenI18n 作为独立插件加载，Meteor 本体保持原样。这意味着你可以在 Meteor 更新后**优先继续使用原版 JAR**，只需确认插件与语言文件是否仍然兼容，而不必等待汉化 JAR 重新打包。这是本方案与“精修汉化包（硬替换 JAR）”之间最根本的区别。

### 语言文件精修

翻译内容以语言文件（`lang.json` 或标准 `assets/.../lang/zh_cn.json`）形式提供。本项目在 dingzhenI18n 内置翻译的基础上，对 Meteor 核心模块的名称、描述和设置项进行了人工复核与修正，减少机器翻译带来的生硬表述。翻译质量的上限取决于精修工作的覆盖范围；未被覆盖的第三方插件模块可能仍显示英文或原始机翻内容。

### 中文渲染修复

dingzhenI18n 本身包含了对 Meteor 自定义字体渲染管线中中文显示问题的修复。不过，字体兼容问题在不同 Minecraft 版本和 Meteor 分支上表现并不完全一致。如果启用后仍有模块名称显示为空白或方框，通常需要在 Meteor 设置中将**自定义字体切换为任意支持中文的字体**，或关闭自定义字体、回退至默认字体渲染。

### 安装形态轻量

无需构建整合包，也无需解压 Meteor JAR。将 dingzhenI18n 插件放入 `mods`，配合语言文件即可生效。语言文件既可以由插件自动读取版本根目录的 `lang.json`，也可以按标准资源包路径放置（`assets/<namespace>/lang/zh_cn.json`），具体取决于你使用的插件版本与 Meteor 版本的适配情况。


## 安装说明

### 前置要求

- **Minecraft**：Java 版，已安装 **Fabric Loader**
- **Fabric API**：与 Minecraft 版本匹配
- **Meteor Client 原版**：确认 Meteor 本体可正常运行
- **dingzhenI18n 插件**：`Meteor-I18n-Support-plugin` 的 JAR 文件

> dingzhenI18n 的版本兼容性与 Meteor 版本相关。插件 README 标注其理论可同步支持其他大部分 Meteor 插件，但作者明确说明“未进行全面的测试”，与其他插件同时使用时存在小概率冲突。安装前请确认插件版本与你的 Meteor 发行版大致对应。

### 安装步骤

1. 关闭 Minecraft。
2. 进入版本目录下的 `mods` 文件夹。
3. 将 **Meteor 本体 JAR** 与 **dingzhenI18n 插件 JAR** 同时放入 `mods`。两者缺一不可。
4. **不要**再放入任何“硬替换汉化版”的 Meteor JAR。本方案与替换型汉化包互斥，二者同时存在会导致类加载冲突。
5. 按插件版本要求放置语言文件。若插件依赖版本根目录的 `lang.json`，将该文件放入 `.minecraft`（或对应版本隔离目录）的根目录；若使用标准资源包结构，则将 `zh_cn.json` 放入 `assets/meteor-client/lang/` 路径下。建议首次安装时先按插件 README 的指引操作。
6. 启动游戏，按 **右 Shift** 打开 Meteor 菜单，检查中文是否正常显示。


## 使用方法

### 确认汉化已生效

进入游戏后打开 Meteor 界面。如果菜单项仍为英文，优先检查两项：dingzhenI18n 插件是否已加载（可在 Meteor 的插件列表中确认），以及语言文件路径是否正确。插件本身不会“自动翻译所有内容”，它提供的是语言文件支持机制；翻译文本由语言文件决定。

### 字体设置建议

如果在开启汉化后遇到模块名称显示为空白、方框或截断，进入 Meteor 的 GUI/字体设置：

- 将**自定义字体**切换为任意支持中文的字体（如系统自带的黑体、微软雅黑等）；或
- 直接**关闭自定义字体**，使用默认字体渲染。

这两条路径均可解决大部分中文显示异常。dingzhenI18n 已包含字体修复逻辑，但不同 Meteor 构建分支对修复的响应可能存在差异。

### 语言文件的维护与替换

本项目的主要交付物是**精修后的语言文件**。如果你希望自行调整翻译，直接编辑对应的 `lang.json` 或 `zh_cn.json` 即可，无需触碰插件 JAR 或 Meteor 本体。这是该方案在可维护性上的核心优势：翻译与程序逻辑分离，更新翻译不会影响插件功能，更新插件也不会覆盖你的语言文件。

### 与其他 Meteor 插件的配合

dingzhenI18n 设计上可同步支持其他 Meteor 插件的语言文件注入。但“理论上支持”不等于“在所有插件上经过验证”。如果你在使用某个第三方 Meteor 插件后出现崩溃，可以尝试暂时移除 dingzhenI18n，以排除插件间冲突。对于未被本项目精修覆盖的插件模块，其翻译质量取决于原始语言文件或插件的自带翻译。


## 兼容性说明

| 项目 | 说明 |
|---|---|
| **与硬替换汉化包** | **互斥**。本方案依赖原版 Meteor JAR + dingzhenI18n 插件，不能与“精修汉化版 JAR”同时放入 `mods` |
| **Meteor 版本** | dingzhenI18n 的维护状态直接影响可用性。插件 README 曾提示 `MeteorCN` 可能不再更新，因此较新的 Meteor 版本是否可用，需以插件仓库的最新发布为准 |
| **Minecraft 版本** | 插件与语言文件的兼容范围由 dingzhenI18n 的构建版本决定。跨多个 Minecraft 大版本使用同一份 JAR 通常不可行 |
| **第三方 Meteor 插件** | 支持语言文件注入，但未经全面测试；存在小概率冲突，崩溃时可优先尝试移除本插件 |
| **翻译覆盖范围** | 精修主要覆盖 Meteor 核心模块。部分第三方插件模块可能仍为英文或未经人工校订的机器翻译 |

> **关于版本维护的现实判断**：dingzhenI18n 是以个人维护为主的社区项目，其更新节奏不一定能紧跟 Meteor 每一次发行。如果你需要的 Meteor 版本尚无对应的插件构建，替代方案包括：使用其他仍在维护的 I18n 支持插件，或退回到与插件兼容的 Meteor 版本。精修语言文件本身通常可以跨插件构建复用，前提是翻译键名与目标插件保持一致。


## 注意事项

**dingzhenI18n 是第三方插件，并非 Meteor 官方组件。** 它通过 Mixin 修改 Meteor 的文本加载逻辑，这在原理上是安全的，但任何 Mixin 插件都存在与特定 Meteor 构建不兼容的可能。插件作者已明确说明未进行全面测试，请自行承担使用风险。

**“精修”是有限度的。** 本项目致力于提升核心模块的翻译质量，但不承诺覆盖全部文本，也不承诺翻译的绝对准确性。未覆盖部分以插件自带语言文件或原文为准。

**请遵守服务器规则。** Meteor Client 本身具有修改客户端行为的能力，汉化方案不改变这一性质。在多人服务器中使用前，请确认相关功能是否符合该服务器的规定。
