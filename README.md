# Meteor Client 精修中文汉化版 (Meteor-CN-Reborn)

> 基于 dingzhen I18n 项目深度优化，修复了大量机翻错误与逻辑错位，专为 PVP 玩家打造。

## 主要改进
- **纠错修复**：修复了原汉化中约 200 处张冠李戴的描述错误（如锚光环与射箭模块描述混淆）。
- **术语润色**：统一了 PVP 黑话（如将“飞船”改为“船飞”，“自我网”改为“自我蜘蛛网”）。
- **Baritone 重译**：彻底重写了 Baritone 寻路模块的机翻文本，使其符合中文逻辑。
- **全模组覆盖**：不仅包含 Meteor 官方模块，还汉化了大量常用 Addon（如 Meteor+, Auto-Obsidian-Farm 等）。

## 安装方法

### 方法一：直接替换客户端（推荐）
1. 下载最新的 `Meteor-CN-Reborn-x.x.x.jar`。
2. 将其放入 `.minecraft/mods/` 文件夹。
3. 启动游戏即可自动加载中文。

### 方法二：仅替换语言文件
1. 下载 `zh_cn.json`。
2. 放入 `.minecraft/meteor-client/lang/` 文件夹。
3. 进入游戏按 `F3 + T` 重载资源或重启游戏。
